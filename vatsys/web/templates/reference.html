Reference lists

Goods and services whose VAT treatment a document sets, such as the zero-rated and exempt schedules of the VAT (General) Regulations (SI 273 of 2003). Each transaction's description is matched against these items, so "2 packets of sugar" is classified by what the loaded list says about sugar, with the document cited as the reason. Rules set up for a business run first; rules for all businesses run after the lists. Descriptions that match nothing are assumed standard-rated and flagged for review.
